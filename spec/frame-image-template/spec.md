| 항목 | 값 |

| 상위 | docs/specs/FEAT-sticky-redesign.md |

## 문제 — 판이 메모보다 눈에 띄고, 틀은 정해진 것만 쓴다
- 판이 금속 테두리와 흰 면으로 그려져 메모보다 무겁게 보인다.
- 판 모양은 자유와 세로 칸뿐이다. 회고판·주간표 같은 자기 틀을 깔 수 없다.
- 세로 칸은 칸 추가·이름·폭 규칙까지 코드가 많지만, 칸은 그림일 뿐이다.

## 목표 — 판은 피그마 그룹처럼 가볍고, 틀은 이미지 한 장으로 깐다
판은 얇은 선과 바깥 이름표만 남는다. 사용자는 우클릭으로 이미지 한 장을 판 배경 템플릿으로 올리고, 바꾸고, 지운다. 소속·같이 옮기기·"착" 모션 같은 판 동작은 그대로다. 판 위의 메모는 흰 종이 대신 정사각형 색종이 포스트잇으로 보인다.

목업: 대화에서 보인 `memo-board-group-template.html`(지금 / 그룹 선 / 템플릿 이미지 세 장면)과 `memo-postit-variants.html`(포스트잇 모양 네 가지). 노드 근거 폴더에는 구현 뒤 실화면 캡처를 둔다.

## 비목표
- 배경 이미지 안의 칸이나 글자를 읽어 메모를 분류하지 않는다. 이미지는 그림이다.
- 템플릿 갤러리·기본 제공 템플릿은 만들지 않는다. 사용자가 올린 이미지 한 장뿐이다.
- 판 안에 판 넣기, 판 연결선은 계속 막는다.
- 소속 판정 규칙(메모 중심점)은 바꾸지 않는다.

## 성공 기준 — 행 파일이 곧 성공 기준이다
rows/T1~T9가 기준이다. 결정은 rows/D1~D7이다. 모두 되돌리기 쉬워 추천값으로 진행하고, 사람이 보드에서 바꾸면 다시 맞춘다.

## 경계 조건
- 배경 이미지 한도와 형식은 사진 카드와 같다(`attachmentLimits.ts`: 10MB, png·jpeg·gif·webp·svg).
- 판 한 장에 배경 이미지는 하나다. 다시 올리면 바꾼다.
- 배경을 바꾸거나 판 크기를 바꿔 판이 커지거나 줄면, 손으로 리사이즈할 때처럼 소속을 다시 판정한다.
- 판 삭제는 되돌리기 없이 바로 지운다(지금 동작). 배경 이미지 파일도 그때 지운다.
- 공유 보드에서는 사진 카드처럼 올린 뒤 다른 사람에게 내려간다(`storeAttachment` 경로).

## 기술 결정
- **배경은 판 행의 `attachmentRef`·`mediaType`에 둔다.** 사진 카드가 이미 쓰는 칸이다. 공유 동기화 모델(`ydoc/model.ts`)과 moss 번들 첨부 수집(`export/attachments.ts`)이 이 칸을 이미 싣는다. 새 칸·새 테이블을 만들지 않는다.
- 이미지 원본 크기(w·h)는 판 `content` 제이슨에 `bg: { w, h }`로 둔다. 비율 맞춤에 쓴다.
- 저장은 `canvasCapture.ts`의 `storePhoto`를 그대로 쓴다(한도 검사·기기 안 저장·크기 읽기).
- 세로 칸의 칸 데이터(`columns`)는 지우지 않는다. 읽기만 그만둔다.

## DAG

```
n1-group-line ──────────────┐
  │                         ├──> n3-bg-ui ──> n4-retire-columns ──> n6-finish
  │  n2-bg-store ───────────┤                                        ^  ^
  │                         └──> n5-export ──────────────────────────┘  │
  └──> n7-memo-postit ──────────────────────────────────────────────────┘
```

진입점은 n1·n2(병렬). 가장 긴 경로는 n1 → n3 → n4 → n6(4단, 노드 7개). n7은 n1 뒤에 n3과 나란히 돈다.

edge 사유:
- n1 → n3: 둘 다 `cards/frame/Content.tsx`를 고친다. n3은 n1이 만든 선·이름표 위에 배경을 깐다.
- n2 → n3: n3 메뉴가 n2의 `setFrameBackground`·`clearFrameBackground`를 부른다.
- n3 → n4: 둘 다 `DraggableCard.tsx`의 판 우클릭 메뉴를 고친다(n3이 판 모양을 배경 메뉴로 바꾸고, n4가 남은 스킨 코드를 걷는다).
- n2 → n5: n5가 n2의 `bg` 크기와 `attachmentRef` 규칙을 내보낸다.
- n4·n5 → n6: 마감은 모든 화면과 내보내기가 끝난 빌드에서 본다.
- n1 → n7: 둘 다 `DockDragPreview.tsx`를 고친다.
- n7 → n6: 마감 캡처에 포스트잇 메모가 들어가야 한다.

커버리지: 판 모양 → n1, 배경 저장 → n2, 메뉴·그리기 → n3, 옛 스킨 → n4, 내보내기 → n5, 사람 확인·문서 → n6, 메모 모양 → n7.
