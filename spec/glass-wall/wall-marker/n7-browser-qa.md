## 문제

단위 테스트로는 들린 마카 모양, 획 겹침 순서, 태블릿 손가락 동작을 판정할 수 없다.

## 목표

dev 서버에서 시안 01·03-b·04·05와 대조해 작업 행의 Then을 하나씩 확인하고 결과표를 남긴다. 담당 행: T1~T12, T14, T17~T19의 화면 확인.

## 작업

1. `cd web && npm run dev`로 띄운다. 이미 떠 있으면 `curl localhost:3000`로 moss인지 확인하고 재사용한다.
2. pharos 브라우저 pane에서 데스크톱 크기로 T1~T10, T17~T19를 행의 Given·When대로 해 보고 스크린샷을 남긴다. 키 입력은 백그라운드 webview에 안 들어갈 수 있다 — 그 행은 "포그라운드에서 확인 필요"로 적는다.
3. 창을 390px 폭으로 줄여 T14를 본다.
4. T11은 같은 공유 보드를 창 두 개로 연다. 로그인이 안 되면 "재현 못 함"으로 적는다.
5. T12는 실기기 태블릿이 있을 때만 본다. 없으면 "실기기 필요"로 적는다.
6. 확인용으로 만든 보드와 메모는 끝나면 지운다.

### 넘겨받은 사실 6개 대조

1. **마카를 든 채 text 포스트잇 위에서 그을 때 벽 획이 같이 생기는가** — 안 생긴다(T7: 벽 4→4, 포스트잇 획만 +1).
2. **기운 포스트잇 + 줌 + 팬에서 선이 포인터와 어긋나는가** — 안 어긋난다. text 포스트잇의 기울기는 id 해시로 최대 ±1.5°라(5°는 단위 테스트 값이고 실제로는 안 나온다) 가장 기운 두 장(+1.32°, −0.85°)에서 줌 110%·팬 뒤 21점 획을 그어 폴리라인을 화면 좌표로 되돌려 대조했다. 포인터 경로와의 최대 거리 0.07px·0.06px.
3. **펜 획이 포스트잇 밖으로 나갔다 들어올 때 끊기지 않는가** — **확인 못 함(실기기 사람 확인)**. CDP 마우스에서는 `setPointerCapture`가 순수 테스트 요소(`pointer-events:auto` svg)에서도 안 먹어서(캡처 뒤 이동·놓기가 안 온다) 이 앱의 캡처 여부를 가를 수 없다. 부수 관찰: 캡처가 안 되는 이 환경에서는 박스 밖에서 이벤트가 안 와서, 나갔다 들어온 획이 나간 점과 들어온 첫 점을 직선으로 이어 박스 가장자리를 따라 가짜 선이 생긴다(`wm7-18-leave-reenter-bridge.png`). 실브라우저에서 캡처가 되면 `clipStrokeToBox`가 조각으로 잘라 이 선이 없어야 한다 — 실기기에서 같은 동작을 해 봐야 한다.
4. **앞면 획 위치가 05 시안과 같은가** — 획은 그은 자리 그대로 남는다(밑줄이 '금요일' 글자 바로 아래, T4). 다만 앞면은 제목이 가운데 한 줄이라 시안(왼쪽 위에서 시작하는 손글씨 두 줄)과 글 배치가 다르다.
5. **트레이 모양·들린 자세·포인터·패널 위치·독 폭** — 아래 「시안과 다른 점」.
6. **천 반경이 벽과 포스트잇에서 같은가** — **다르다(수치 근거)**. 벽 12px 고정(`WALL_CLOTH_RADIUS_PX`), 포스트잇은 자기 좌표 8이라 화면에서는 `8 × 줌`이다. 줌 86%에서 재 보니 벽은 획과 문지른 줄 사이 10px에서 지워지고 12px에서 남았고, 포스트잇은 5px에서 지워지고 7px에서 남았다. 같게 만들지는 marker-feel 몫이다.

### 사람 확인이 필요한 것

- 실제 펜·손바닥: 펜 압력, 손바닥 오입력 방어, 펜이 포스트잇 밖으로 나갔다 들어올 때 끊기는지(위 3).
- 두 손가락 핀치(T12): 그리는 중 두 번째 손가락 → 긋던 획 버림 → 줌, 그 뒤 다시 긋기. CDP에서 한 번 본 「핀치 뒤 단일 터치 획이 안 들어감」은 실기기에서 `touchesRef`가 남는지로 확인해야 한다.
- 공유 보드(T11·T18의 공유 부분): 두 기기 동시 획, 내 획만 되돌리기, 옮긴 위치가 상대 화면에 보이는지.
- 손맛: 마카 들린 자세, 벽·포스트잇 천 반경 체감, 고르기 상자·묶음 끌기 감각.

### 다음 노드가 알아야 할 것

- **첫 맞춤이 카드만 본다.** 벽 획만 있는 영역이 카드에서 떨어져 있으면 새로고침·휴대폰에서 처음 화면에 안 보인다(T14 관찰). 카드 밖 벽 획을 맞춤에 넣을지는 wall-zoom 몫이다.
- **천 반경이 벽(화면 12px)과 포스트잇(8×줌)에서 다르다.** 위 6.
