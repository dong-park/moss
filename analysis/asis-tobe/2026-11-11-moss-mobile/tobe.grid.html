1선택한 카드에 편집·이동을 표시 — 탭은 선택으로 유지한다. 「편집」을 눌러 입력을 시작한다.
2터치 영역은 화면 기준 44px — 캔버스가 작아져도 버튼을 누를 크기는 유지한다.
3새 메모는 바로 전용 편집 화면 — 제목과 본문을 한 자리에서 쓴다. 키보드 높이에 맞춰 영역을 조절한다.
4완료 버튼은 키보드 위에 고정 — 「완료」로 편집을 끝내고 원래 보드로 돌아간다.
5읽기 상태로 열고, 편집은 명시적으로 — 기본은 키보드 없이 본다. 「편집」을 누르면 키보드가 열린다.
6뒤로가기는 현재 화면부터 닫는다 — 읽는 중: 상세 → 보드. 편집 중: 키보드 → 상세 → 보드.
