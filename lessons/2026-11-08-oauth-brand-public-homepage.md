# Google 브랜딩 인증을 내기 전에 홈페이지를 로그아웃 상태로 연다

## 맥락

2026-11-08 moss 전용 OAuth 프로젝트에서 브랜딩 홈페이지를 `https://moss.dongpark.dev`로 두고 "브랜딩 확인"을 눌렀다. 5분 뒤 자동 점검이 떨어뜨렸다. 사유는 "로그인 페이지가 홈페이지보다 먼저 표시됩니다"였다. moss의 `/`는 로그인 전이면 바로 로그인 온보딩을 띄운다. 인증 전이라 계정 선택 창에는 앱 이름 대신 도메인이 계속 보였다.

## 다음에 할 일

- 브랜딩 인증을 내기 전에 홈페이지 주소를 로그아웃 브라우저로 연다.
- 로그인 창 없이 앱 이름, 기능 설명, Google 데이터를 쓰는 목적, 개인정보처리방침 링크가 보이는지 확인한다.
- 첫 화면이 로그인을 요구하면 공개 소개 페이지를 먼저 만들고 그 주소를 홈페이지로 넣는다.

## 검증

로컬에서 `/about`을 로그아웃 브라우저로 열었다. 데스크톱과 375px 폭 모두 `role="dialog"`가 0개였다. Google 재인증 통과는 확인 안 됨. 배포 뒤 다시 낸다.
