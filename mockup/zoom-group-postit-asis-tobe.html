① 포스트잇 카드(메모 앞면)

원인: 오늘 커밋 e37d124(FT-7)이 메모 앞면을 종이 사진 cards/v2/text.png와 옅은 색조(multiply)에서 CSS 면(접착 띠, 잡음 결, 진한 노랑)으로 바꿨습니다. 팔레트도 진한 색으로 바뀌었습니다. 도크 아이콘은 그대로 둡니다.

AS-ISCSS 포스트잇 (e37d124)

TO-BE예전 종이 사진 + 옅은 색조 (e37d124 이전)

되돌리는 범위: text/Content.tsx의 종이 배경과 색조 층, memoVariety.ts 팔레트(노랑 6단계와 파랑·라임·보라·분홍), DockDragPreview.tsx 끌기 미리보기. 메모에 저장된 값은 색 이름이라 데이터를 고칠 필요가 없습니다.

② 그룹(메모판) 가시성

원인: 판 선 #dadbde 1px과 배경 #ebecee의 대비가 약 1.1:1입니다. 이름표는 12px 회색이고 줌과 함께 작아집니다(50%에서 선 0.5px, 글씨 6px).

AS-IS100% · 50%

TO-BE옅은 면 + 진한 선 + 화면 고정 이름표

판 안쪽에 흰 면(45%)을 깔고 선은 #aeb2ba로 바꿨습니다. 선은 화면 기준 1px, 이름표는 화면 기준 12px로 고정해 줌을 줄여도 같은 크기로 보입니다.

③ 줌 구간별 표시 정책

원인: 캔버스 전체에 CSS scale() 하나만 걸려 있어 모든 요소가 같은 비율로 작아집니다. 범위는 0.5~1.1배이고, 축소했을 때의 요약 표시(LOD)가 없습니다.

AS-IS균일 축소

TO-BE구간마다 다르게 그림

구간(제안)메모판그림자·기울기·결
가까이 ≥ 80%그대로선 1px, 이름표 12px (화면 고정)켬
보통 40~80%본문 글씨는 화면 기준 최소 10px로 키우고, 넘치는 줄은 자름화면 고정그림자 약하게
멀리 < 40%글씨 대신 회색 줄 2개(형태만)면 색 진하게 + 이름표 13px 굵게. 이름으로 지도처럼 읽음끔 (성능)

AS-IS의 25% 칸은 현재 최소 줌(50%)보다 작아 실제로는 갈 수 없는 화면입니다. 최소 줌을 낮출지는 따로 결정할 사항입니다.
